# Day 1 - Task

## Task:

- Analyze three existing Claude Skills and explain when each should be triggered and what problem it solves.

## Table of three skills

| Skills                                                                             | When should it be triggered?                                                                                                                         | What problem does it solve?                                                                                                                                                     | Why is it a Skill instead of a normal prompt?                                                                                                                                                                                      |
| ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [PDF skills](https://github.com/anthropics/skills/blob/main/skills/pdf/SKILL.md)   | When the user's request involves working with PDF documents, such as creating, editing, merging, splitting, or extracting content.                   | Simplifies common PDF operations by providing a consistent workflow for creating, editing, extracting, merging, and splitting PDF documents.                                    | Because it packages reusable expertise, instructions, and tools for PDF workflows, allowing Claude to load them only when needed instead of including them in every conversation.                                                  |
| [PPTX skills](https://github.com/anthropics/skills/blob/main/skills/pptx/SKILL.md) | When the user needs to create, edit, analyze, or convert PowerPoint presentations, or when a `.pptx` or `.potx` file is involved as input or output. | Provides a structured workflow for generating, modifying, and extracting content from PowerPoint presentations while preserving formatting and slide structure                  | It packages specialized presentation-generation expertise, formatting rules, and reusable workflows that Claude loads only when presentation-related tasks are requested.                                                          |
| [XLSX skills](https://github.com/anthropics/skills/blob/main/skills/xlsx/SKILL.md) | When the user references a spreadsheet file (e.g. `.xlsx` , `.csv`) by name or path.                                                                 | Provides a structured workflow for spreadsheet creation, data analysis, formatting, calculations, and chart generation, reducing manual effort and ensuring consistent results. | It encapsulates specialized spreadsheet expertise, predefined workflows, and best practices that Claude can load only when spreadsheet-related tasks are requested, instead of including these instructions in every conversation. |
