# Week 7 — Capstone: CollaInsight MVP

## Overview

**CollaInsight** is the final capstone project for the summer training program.

The project was developed progressively throughout the training and brings
together concepts practiced in previous weeks, including Agentic AI,
tool calling, APIs, n8n automation, structured LLM extraction, backend
integration, and AI-assisted knowledge analysis.

CollaInsight addresses a common problem in team communication:
valuable knowledge such as ideas, decisions, questions, suggestions,
action items, and observations can become buried inside high-volume
conversations.

The MVP transforms explicitly submitted Telegram messages into structured,
reviewable organizational knowledge that can be explored through a
manager-facing dashboard.

## Capstone Coverage

The final MVP demonstrates:

- Agentic AI with LangGraph
- Tool calling and duplicate checking
- n8n workflow automation
- Telegram integration
- Structured AI extraction
- FastAPI backend
- Supabase / PostgreSQL storage
- React manager dashboard
- Grounded AI Insights
- Human confirmation for the five n8n-native knowledge flows
